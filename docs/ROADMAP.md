# Wattwise roadmap

A direction for discussion, not a delivery commitment. Hardware access, reproducible tests and honest measurement labels take priority over adding impressive-looking numbers.

## Available now

- [x] Browser demo, estimates, energy charts, tariffs and CSV reports.
- [x] Windows x64 desktop preview with tray tracking and local history.
- [x] Supported battery discharge readings and charging diagnostics.
- [x] Process CPU activity with unavailable/stale states.
- [x] Tested installer workflow and release checksums.

## Candidate improvements

- [ ] More real-device coverage for charging, charge limits and driver restrictions.
- [ ] Accessibility, localization and clearer setup/troubleshooting flows.
- [ ] A reviewed, privacy-preserving diagnostics export with explicit user consent.
- [ ] Signed releases, subject to certificate selection and secure credential management.
- [ ] Select and document a project license.

## Research required

- [ ] Documented external energy-meter integrations for actual wall-power readings.
- [ ] Hardware-supported CPU/GPU telemetry, without security-policy bypasses.
- [ ] Clearly qualified per-app energy attribution, only with a defensible method and validation.

A driver cannot create a missing physical sensor. CPU share alone will not be labeled as measured app watts. No dates, device support or integrations are promised by this list.
